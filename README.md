# 🐧 Linux Security Basics

A practical Linux security lab focused on system administration, security monitoring, and investigation fundamentals relevant to a **SOC Analyst L1** role.

## 🎯 Objectives

* Understand Linux users, groups, and privileges
* Analyze file and directory permissions
* Monitor processes and system services
* Inspect network connections and listening services
* Understand Linux authentication and security logs
* Develop basic security investigation skills

## 🧪 Lab Environment

* **OS:** Linux / Kali Linux
* **Focus:** Blue Team & SOC fundamentals
* **Purpose:** Educational and authorized security practice

## 🔐 Security Areas

### 👤 Users & Privileges

* User and group enumeration
* Privilege and `sudo` concepts
* Account security fundamentals
* Understanding privileged activity

### 📁 File Permissions

* Read, write, and execute permissions
* Ownership and groups
* Permission analysis
* SUID / SGID concepts

### ⚙️ Process & Service Monitoring

* Identify running processes
* Review system services
* Understand parent/child processes
* Identify unusual or unexpected activity

### 🌐 Network Investigation

* Identify listening services
* Review active network connections
* Understand ports and protocols
* Perform basic network troubleshooting and investigation

### 📋 Authentication & Security Logs

* Understand authentication events
* Review successful and failed login activity
* Identify relevant Linux log locations
* Practice basic log analysis

## 🔎 SOC Investigation Approach

For each investigation, I will document:

1. **What happened?**
2. **What evidence was observed?**
3. **Is the activity expected or suspicious?**
4. **What additional information should an L1 analyst collect?**
5. **What action or escalation would be appropriate?**

## 📊 Practical Evidence

This repository will contain:

* Command outputs
* Investigation notes
* Relevant screenshots
* Security observations
* Lessons learned

> Sensitive information such as passwords, API keys, tokens, and private data will not be included.

## 📚 Learning Outcomes

Through these labs, I am building practical knowledge of:

* Authentication monitoring
* Network investigation
* Log analysis
* SOC Analyst L1 investigation methodology
